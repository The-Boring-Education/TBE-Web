# TBE Web — Release v2.16.4

**Release date:** July 2, 2026
**Status:** Published (production release, not a pre-release)
**Compare:** [v2.16.3...v2.16.4](https://github.com/The-Boring-Education/TBE-Web/compare/v2.16.3...v2.16.4)

## New

- **Freemium preview for OnCampus prep content.** Free users can now try the first 30% of chapters, topics, and questions across Core Subjects, Aptitude Preparation, and Interview Sheets before hitting an upgrade prompt — paid users continue to get full access.
- **Standalone Pattern Quiz.** The DSA pattern-recognition quiz moved off the main dashboard onto its own page (`/pattern-quiz`) and is now also available to OnCampus users, not just DSA Yatra.
- **Activation analytics.** GA4 tracking was added to measure user activation, giving the team visibility into how new users move through the product.
- **Admin console (internal).** A new internal admin application was introduced for managing users, courses, and quizzes — this is a team-facing tool and does not change the learner-facing product.

## Improved

- **Checkout page** is more compact — tighter spacing and sizing mean the full order summary now fits on screen without scrolling.
- **Onboarding flow** no longer flashes the dashboard before redirecting users who haven't completed onboarding.
- **DSA Yatra study workspace:** the back button from the study guide now returns you to the current topic's question list instead of the full roadmap, the duplicate "Progress" menu item was removed, and question tabs/company tags now wrap cleanly on mobile instead of causing a horizontal scrollbar.
- **Aptitude Preparation** moved to its own dedicated route outside the dashboard shell, with a cleaner full-width unlock banner.

## Fixed

- **Core Subjects API** now enforces the logged-in user's session instead of trusting a query-parameter user ID, closing a gap where one user's data could potentially be requested using another user's ID.
- **Prep-Yatra goal timeline** was showing a raw internal value instead of a readable label; it now displays correctly formatted text.
- Minor accessibility and navigation fixes for the back button used across study/prep flows.

## Breaking

- None. This release contains no breaking changes.
