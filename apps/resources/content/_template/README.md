# New resource template

1. Copy this folder to `content/<your-slug>/` (slug: lowercase, hyphens, no spaces).
2. Edit `meta.json` — `title` and `description` are required (used for SEO and Open Graph).
3. Edit `index.html` — full HTML document; include `<meta name="viewport" ...>` for mobile.
4. Open a PR. After merge and deploy, the page is live at `/resources/<your-slug>`.

Do not commit this `_template` folder as a published resource — it is for copying only.
